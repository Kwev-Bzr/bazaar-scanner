Bazaar Scanner

Nothing to configure here: everything is set in the companion app.

This extension needs a small application running on your PC. Without it, your viewers will see nothing: the extension only displays what the app sends.

Getting started

  1. Download the installer from the releases page.
  2. Run it. It installs the app and the game mod, for the Steam version of the game or the Tempo launcher.
  3. Launch Bazaar Scanner and click Connect.
  4. Start a run: your viewers can now hover over your items.

If your game does not fill your whole scene in OBS, open Layout in the app so the hover zones line up with your scene.

Bazaar Scanner

Rien à régler ici : tout se configure dans l'application compagnon.

Cette extension a besoin d'une petite application sur votre PC. Sans elle, vos spectateurs ne verront rien : l'extension n'affiche que ce que l'application lui envoie.

Pour commencer

  1. Téléchargez l'installateur depuis la page des versions.
  2. Lancez-le. Il installe l'application et le mod, pour la version Steam du jeu ou le client Tempo.
  3. Ouvrez Bazaar Scanner et cliquez sur Se connecter.
  4. Lancez une partie : vos spectateurs peuvent désormais survoler vos objets.

Si le jeu n'occupe pas toute votre scène OBS, ouvrez Cadrage dans l'application pour que les zones de survol correspondent à votre scène.
